# 🚗 Calculadora de Consumo de Combustível

## 📝 Descrição
A **Calculadora de Consumo de Combustível** é uma aplicação web simples e interativa desenvolvida com **HTML, CSS e JavaScript**.  
O objetivo do projeto é permitir que o usuário calcule o **consumo médio de combustível (km/l)** de forma rápida, prática e intuitiva.  
A aplicação foi criada com foco em **usabilidade, aprendizado e aplicação de lógica de programação** no desenvolvimento front-end.

---

## ⚙️ Funcionalidades
✅ Inserir **distância percorrida (km)** e **quantidade de combustível abastecida (litros)**  
✅ Calcular automaticamente o **consumo médio (km/l)**  
✅ Exibir o resultado de forma clara e imediata  
✅ Exibir **alertas personalizados** para campos vazios ou inválidos  
✅ Design **responsivo** e interface **amigável**

---

## 🧠 Tecnologias Utilizadas
- **HTML5** → estrutura da aplicação  
- **CSS3** → estilização e responsividade  
- **JavaScript** → lógica de cálculo e interatividade  

---

## 🎯 Objetivo e Aprendizados
Este projeto foi desenvolvido para **reforçar conceitos fundamentais de programação**, como:
- Manipulação do **DOM**  
- Estruturação de formulários  
- Criação de **funções** e **validação de dados**  
- Aplicação prática de lógica de cálculo  

Além disso, demonstra como pequenas aplicações podem gerar **valor real no dia a dia**, auxiliando motoristas a monitorar o desempenho e o consumo de seus veículos.
